This private key lets this page save to the website. The key is made once, and the same key works on your phone, PC and laptop.

Part 1: the owner of the Nafwise GitHub account makes the key

  1. On a computer signed in to GitHub, open this ready-filled key page.
  2. Under Repository access, choose Only select repositories, then pick The-Secret-DnB-Society. This is the one part you have to set by hand.
  3. Check Contents shows Read and write, then press Generate token and copy the key. GitHub only shows it once.
  4. Send it to the admin in one private message. Delete the message once every device is connected.

Part 2: the admin connects each device

Do this once on each phone, PC or laptop you want to use. A device stays connected after you sign out.

  1. Open the website on that device, click the padlock and sign in.
  2. Copy the whole key from the message.
  3. Paste it in the box below and press Connect.

Each web browser counts as its own device, so use the same one each time.

Treat this key like a bank card. Anyone who has it can change the website. Never post it publicly or put it anywhere on the page. If it gets out, delete it at GitHub's key page and make a new one.

You make one Stripe Payment Link for each thing you sell, then paste it next to that item here. This needs no extra hosting.

Set up Stripe

  1. Make an account at stripe.com and fill in your business and bank details so you can be paid.

Make a link for each ticket or merch item

  1. In Stripe, open Payment Links and press + New.
  2. Press + Add a new product. Enter the name, photo and price in GBP, then press Add product.
  3. Look through the options on that screen. Turn on the one that lets customers adjust the quantity. For merch, turn on collecting the customer's address so you know where to post it.
  4. Press Create link, then copy the link.
  5. Back here, open Events or Merch, paste it into Stripe payment link on the right item, and press Publish to live site.
  6. Buy one yourself to check it works, then refund it from Stripe.
Never paste a Stripe "secret key" (it starts with sk_) into this page. Only ever paste Payment Links.
